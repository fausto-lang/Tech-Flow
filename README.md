# ME voy de vacaciones esto es todas las mejoras antes de irme , regrso el martes


- Ahora es una sola ventana moderna, ya no se abre una ventana encima de la otra.
- La ventana anterior peleaba con bspwm y se trababa, ahora se acomoda bien como un solo recuadro.
- Nueva clase Navegador, que es la que se encarga de cambiar de pantalla sin abrir ventanas nuevas.
- Las pantallas de login, administrador, vendedor y almacén cambian con una transición suave, ya no es un corte seco.
- Los formularios y avisos ya no salen como ventanas flotantes, salen como cuadritos dentro de la misma ventana.
- La ventana quedó más chica y más ancha, para que no se salga de la pantalla.
- En ventas ya no se desborda el contenido, todo cabe y hay scroll cuando hace falta.
- La tarjeta de la caja quedó más chiquita, acorde a lo que muestra.
- El panel de entradas de almacén quedó más ancho, ya no se corta lo de la derecha.
- Los avisos cortos quedaron chiquitos, como deben ser.
- Al importar un CSV ahora sale una vista previa con todo lo que trae, podés ver si está completo y confirmar a propósito.
- Al terminar una venta sale un cuadro con el resumen, para guardar el archivo o cerrar, ya no se imprime en la terminal.
- En el login hay un botón para cambiar entre tono claro y oscuro, y el tono que elegís queda para toda la sesión.
