\section{Notas de comportamiento visible}
\begin{itemize}
\item El punto de venta muestra el mismo precio que la factura y el CSV registran (antes: precio distinto).
\item Los informes y la proforma truncan celdas excesivamente largas con «…».
\item La consola acepta nombres alfanuméricos para empleados, proveedores y clientes.
\item Selecciones y campos vacíos del filtro: el filtro por defecto muestra \emph{Todas}.
\end{itemize}
